# Changelog

All notable changes to **VelocityHUD** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-27

### Added
- **Multi-Loader Support**: Fabric, Forge, Quilt, NeoForge.
- **Real-Time Speed Calculation**: 3D and 2D horizontal speed calculations.
- **Multiple Units**: Blocks/sec (`b/s`), Kilometers/hour (`km/h`), Miles/hour (`mph`), Meters/sec (`m/s`).
- **HUD Renderer**: Customizable position (9 screen anchors), background toggle, custom color, scale, and offset.
- **Keybinding**: Toggle HUD visibility in-game (`V` key by default).
- **JSON Configuration**: Auto-saving config file (`config/velocityhud.json`).
- **Unit Tests**: Full test coverage for core speed calculation and unit conversion math.
- **CI/CD**: GitHub Actions workflows for automated build, test, and release.
