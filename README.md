# VelocityHUD

A Minecraft mod that displays real-time velocity on the HUD.

## Features
- Real-time velocity display (blocks/second)
- Configurable position and style
- Compatible with Fabric, Forge, Quilt, and NeoForge

## Building

```bash
./gradlew build
```

## Development

This is a multi-loader project. The `common` module contains shared code, while loader-specific modules handle platform integration.
